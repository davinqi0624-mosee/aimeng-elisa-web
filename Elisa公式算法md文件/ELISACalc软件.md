ELISACalc是一款回归和拟合数据的计算程序，能够用来计算直线回归、二次三次曲线回归、四参数曲线回归等。建议使用四参数回归曲线。ELISACalc软件与CurveExpert相比较，能选取的拟合模型种类较少，优点是操作简单，可以结合excel表格处理数据方便复制粘贴，计算大批量数据时有明显优势。

**绘制方法如下：**

1、在EXCEL表格中整理一组包括标曲和样本数据。

| 标准品    | 样本OD值 |        |        |        |
| --------- | -------- | ------ | ------ | ------ |
| 浓度pg/ml | OD值     |        |        |        |
| 0         | 0.0323   | 0.5227 | 0.5287 | 0.6105 |
| 156       | 0.1004   | 0.6302 | 0.6404 | 0.875  |
| 312       | 0.2003   | 0.4723 | 0.4829 | 0.4271 |
| 625       | 0.3464   | 0.4992 | 0.5065 | 0.9242 |
| 1250      | 0.5472   | 0.6473 | 0.6524 | 1.2026 |
| 2500      | 0.8945   | 0.4999 | 0.5069 | 0.8086 |
| 5000      | 1.3647   | 1.2535 | 1.2665 | 0.9042 |
| 10000     | 1.9448   | 1.5922 | 1.5855 | 0.8102 |

2、打开软件ELISACalc，复制表格中底色填充为粉色的数据，点击软件中的“粘贴”按钮，如图:

![img](https://boster.com/uploads/20231009/dc5a91baf3028be4158c9bdd8de51723.png)

3、左上角优先选择四参数拟合曲线，点击“回归/拟合”模型，得到如下曲线图：

![img](https://boster.com/uploads/20231009/e24c3a49eab4c0e976c1ab0d6796d2a7.png)

4、曲线应为平滑上升趋势，r2值越接近 1 拟合度越好。如果四参数模型不理想可以换成其他的模型。依次点击“回归方程”“复制”，可以把方程粘贴到表格中。

![img](https://boster.com/uploads/20231009/5f839fc6445f31a35afda82da46bdabc.png)

5、点击“由Y计算X”，复制表格中的样本吸光值即底色为黄色的数据，在软件中点击“粘贴”“计算”。即可得到对应的样本蛋白浓度值。

![img](https://boster.com/uploads/20231009/721d7e78469f146624d8fc1dc1db3402.png)

6、点击“复制”，即可把得到的浓度值粘贴到表格中。整理数据，再乘以稀释倍数，得到对应样本蛋白最终浓度值。

ELISACalc软件与CurveExpert相比较，能选取的拟合模型种类较少，优点是操作简单，可以结合excel表格处理数据方便复制粘贴，计算大批量数据时有明显优势。
