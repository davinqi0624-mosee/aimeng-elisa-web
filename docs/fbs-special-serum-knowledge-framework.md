## 使用原则

这份手册适合作为爱萌优宁网站“胎牛血清 / 特殊血清”知识内容的受控资料源。公开内容应围绕客户真实实验问题展开，形成“知识解释 → 选型判断 → COA/批次资料 → 产品咨询”的闭环。

公开文章中应避免：

- 提及或比较其他品牌。
- 直接复制外部品牌的货号、价格、规格表。
- 写成“某某品牌更好/更差”的横向对比。
- 做绝对化性能承诺，例如“完全无干扰”“一定提高产量”。
- 将研究文献中的特定实验结果直接套用为产品承诺。

公开文章中可以使用：

- 特殊血清的处理原理。
- 常见干扰源和对应选型逻辑。
- COA 指标怎么看。
- 使用注意事项。
- 客户实验场景下的排查思路。
- 爱萌优宁产品页、COA 查询、技术支持入口的自然引导。

## 核心知识主线

特殊胎牛血清的核心不是“增强血清”，而是“去除特定干扰源”。每日知识和 AI 客服应始终围绕这个逻辑：

> 先判断实验中最怕什么干扰，再选择对应的特殊血清。

六类特殊 FBS 可按干扰源分类：

| 特殊血清类型 | 主要解决的问题 | 适合公开讲解的客户语言 |
|---|---|---|
| 四环素阴性 FBS | 四环素系统背景泄漏 | 做 Tet-On/Tet-Off 实验时，血清里残留的四环素可能让基因提前表达。 |
| 透析 FBS | 小分子背景干扰 | 做 SILAC、代谢标记、营养控制实验时，需要去掉血清里原有的小分子。 |
| 碳吸附 FBS | 激素/类固醇背景干扰 | 做激素受体、内分泌、激素敏感细胞实验时，需要降低血清内源激素。 |
| 低脂 FBS | 脂质背景干扰 | 做脂质代谢、胆固醇摄取、脂肪肝模型时，需要低脂质背景。 |
| 低 IgG FBS | 牛源 IgG 干扰 | 做杂交瘤、抗体生产、免疫检测时，需要减少外源 IgG 背景。 |
| 去外泌体 FBS | 牛源外泌体污染 | 做外泌体分离、miRNA 测序、细胞间通讯实验时，需要减少血清外泌体背景。 |

## 每日知识主题库

1. 做 Tet-On/Tet-Off 实验为什么要用四环素阴性血清？
2. 透析胎牛血清和碳吸附胎牛血清有什么区别？
3. 做激素受体实验为什么不建议直接用普通 FBS？
4. 脂质代谢实验为什么需要低脂 FBS？
5. 杂交瘤培养为什么要关注血清里的 IgG？
6. 外泌体实验为什么要用去外泌体 FBS？
7. 六类特殊胎牛血清如何按实验目的选择？
8. 特殊血清是不是所有细胞实验都需要？

### B. COA 与质控类

1. 特殊胎牛血清的 COA 应重点看哪些指标？
2. 四环素阴性 FBS 的残留检测怎么看？
3. 透析 FBS 为什么常看葡萄糖残留？
4. 碳吸附 FBS 为什么要关注雌二醇等激素指标？
5. 低脂 FBS 的胆固醇和甘油三酯指标怎么看？
6. 低 IgG FBS 的 IgG 残留值说明什么？
7. 去外泌体 FBS 为什么要看 NTA 或外泌体标志物？

### C. 使用注意事项类

1. 特殊血清使用前为什么建议做小规模预实验？
2. 为什么特殊血清不一定适合常规扩增培养？
3. 碳吸附血清为什么有时需要提高使用浓度？

5. 去外泌体 FBS 为什么建议分阶段使用？
6. 特殊 FBS 解冻和分装有什么注意事项？
7. 血清出现沉淀或絮状物是否一定不能用？

### D. 实验场景类

1. MCF-7 等激素敏感细胞实验如何选择血清？
2. SILAC 蛋白质组学为什么要用透析 FBS？
3. 肝细胞脂质堆积模型为什么需要低脂背景？
4. 单克隆抗体生产如何降低牛 IgG 背景？
5. 外泌体培养上清收集前为什么要换去外泌体 FBS？
6. 病毒包装系统遇到 Tet 元件时为什么要关注四环素残留？

## 推荐文章结构

胎牛血清每日知识建议固定成短闭环：

1. 问题场景：客户什么时候会遇到这个问题。
2. 背景原理：血清中哪类成分造成干扰。
3. 选型判断：对应哪类特殊血清。
4. 使用提醒：浓度、预实验、分阶段使用、COA 核对。
5. 网站引导：查看血清产品、查询 COA、联系客服。

示例结尾：

> 如果实验对血清批次或特殊处理指标敏感，建议先查看对应批次 COA，并在正式实验前进行小规模细胞适应性验证。如需确认血清类型，可联系爱萌优宁技术支持协助判断。
