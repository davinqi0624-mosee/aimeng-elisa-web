# 2026-07-26 首页视频动态预览增强

## 用户反馈

首页媒体窗口中虽然显示“动态预览”，但实际视觉上仍然像静态封面，不容易让客户感受到视频窗口是活的。

## 修正内容

- 修改 `app/page.tsx`。
- 对非直链视频链接，如剪映/小红书网页链接，新增真正的动态预览：
  - 封面慢速推进/回拉。
  - 扫描线持续移动。
  - 光圈脉冲动效。
  - 右下角数据条跳动。
  - 中部实验脚本卡片自动轮播。
- ELISA 预览脚本：
  - 加样准备
  - 孵育洗板
  - 显色终止
  - 读数分析
- 细胞培养预览脚本：
  - 状态观察
  - 血清选择
  - 污染排查
  - 传代节奏

## 技术说明

- 剪映网页链接不是 MP4/WebM/Ogg 直链，无法直接作为 `<video src>` 播放。
- 现在逻辑为：
  - 直链视频：左侧直接静音循环播放。
  - 网页链接：左侧使用动态预览橱窗，点击“看完整版”跳转平台。

## 验证

- `npx eslint app/page.tsx --quiet`
- `npm run build`
- `npm run deploy:aliyun`
- 线上健康检查通过。
