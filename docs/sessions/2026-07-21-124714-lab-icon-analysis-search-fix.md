# 2026-07-21 实验页图标、ELISA 竖版模板计算与产品模糊搜索修正

## 背景

用户反馈三个问题：

- 实验方案生成器页面红框品牌内容需要去掉，绿框烧瓶图标需要换成用户提供的图片位。
- ELISA 数据分析模板从横向改成竖向后，网站计算结果与其他软件不一致，且标准曲线浓度反算表现异常。
- ELISA 产品搜索没有达到模糊搜索效果，输入 `il6` 不能关联到 `IL-6`。

## 调整

- `app/lab/layout.tsx`
  - 保持移除实验工具页顶部左侧 `AIMENG UNING` 品牌入口。
- `app/lab/experiment/page.tsx`
  - 绿框位置已改成图片位 `/brand/experiment-ai-assistant.png`。
  - 当前使用品牌小蜜蜂透明图作为兜底图片，后续替换同名文件即可换成新图。
- `app/lab/analysis/page.tsx`
  - 修正默认标准品浓度顺序为 `0, 125, 250, 500, 1000, 2000, 4000, 8000`。
  - 修正 A-H 孔位到标准品浓度的映射，和参考文件 `Human LRP1.xlsx` 保持一致。
  - 竖版模板解析时优先读取“浓度/名称”里的数值；如果没有填写数值且标准品在 01 列，则按 A-H 默认映射兜底。
  - 避免把 `S1` 这类标准品编号误识别成浓度 `1`。
- `lib/products/search.ts`
  - 增加字母+数字的目标蛋白变体规则，例如 `il6` 会同时搜索 `il6`、`il-6`、`il 6`。
  - 继续保留希腊字母和货号后缀规格归一化规则。

## 原因说明

新模板不会改变 4PL 算法，但会改变程序读取数据的方式。之前横向模板的数据位置比较固定，竖向模板变成“一孔一行”后，程序必须准确识别：

- 哪些行是标准品；
- 哪些行是检测样本；
- 标准品浓度从哪个单元格读取；
- 没有填写浓度时是否允许按孔位兜底。

本次发现旧代码里的 A-H 默认标准品顺序与参考文件不一致，这是造成计算偏差的主要风险点之一。
