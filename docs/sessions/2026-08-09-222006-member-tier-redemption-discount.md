# 会员等级与积分商城折扣

## 背景

用户希望会员等级从旧的低门槛规则升级为铜/银/金/铂金四级，并且等级按累计获得积分计算，不按当前可用余额计算。用户兑换积分商品后，可用积分减少，但会员等级不应下降。

## 本次修改

- 将会员等级规则集中到 `lib/points/ledger.ts`：
  - 青铜会员：0+ 累计积分，原价兑换
  - 白银会员：3500+ 累计积分，积分商城95折
  - 黄金会员：8000+ 累计积分，积分商城9折
  - 铂金会员：15000+ 累计积分，积分商城88折
- 保持积分账本语义：
  - `earn` 增加可用积分和累计积分
  - `spend` 只减少可用积分
  - `refund` 只退回可用积分，不增加累计积分
- `/api/user/points` 返回会员等级、折扣、下一等级和完整等级规则。
- 会员中心区分展示“可用积分”和“累计积分”，并说明兑换不会降低会员等级。
- 积分商城前台展示会员价，登录后按当前等级显示折扣和节省积分。
- 兑换接口 `/api/shop/redeem` 在服务端重新计算会员折扣，按折扣后的积分扣减，避免前台篡改价格。
