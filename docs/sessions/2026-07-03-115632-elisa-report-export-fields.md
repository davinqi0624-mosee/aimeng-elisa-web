## 已完成

- `app/lab/analysis/page.tsx`
  - Excel 模板改为包含 `标准品孔位`、样本孔位、样本 OD、样本稀释倍数。
  - Excel 模板进一步扩展为完整 96 孔板结构：标准品预填 `A01-H01`，样本孔位预填 `A02-H12`，覆盖 1# 到 11# 样本列。
  - Excel 模板每组样本新增 `样本编号` 列，形成 `孔位 / 样本编号 / OD值 / 稀释倍数` 四列结构。
  - 上传解析会优先读取 `样本编号` 作为报告里的客户样本名称；为空时仍使用系统默认编号兜底。
  - 宽表解析支持读取模板中的孔位与稀释倍数；旧模板仍兼容，未填写孔位时自动按 96 孔位补齐。
  - TXT 报告、Excel `整理后数据`、Excel `报告`、网页 `实验报告` 预览统一保留孔位和稀释倍数，并去掉 CV 与状态/判定列。
  - 保留数据表格页的 CV/判定作为内部质控查看，不进入客户报告导出。
  - 页面输入提示同步改为推荐完整 96 孔模板，说明标准品占 01 列、样本覆盖 02-12 列。

- `app/api/reports/route.ts`
  - HTML 报告表格同步去掉 CV 与判定列。
  - HTML 报告样本结果保留孔位、OD、稀释倍数、反算浓度、最终浓度。
