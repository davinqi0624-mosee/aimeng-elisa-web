# 2026-06-28 F1 首页和公共导航巡检

## 本轮目标

检查首页轮播、导航入口、移动端菜单、客服入口、代理商入口等公共访问链路，优先修复客户访问时容易迷路或落点不准确的问题。

## 已处理

- `components/ui/Navbar.tsx`
  - “联系我们”导航落点改为 `/contact#contact-info`。
  - “全国代理商”导航落点改为 `/contact#agents`。
  - 移动端菜单补充 `aria-label`、`aria-expanded`、`aria-controls`。
  - 移动端菜单增加 `max-h-[calc(100dvh-4rem)] overflow-y-auto`，避免菜单过长时超出手机屏幕。

- `app/contact/page.tsx`
  - 新增 `contact-info` 和 `agents` 锚点。
  - 锚点增加 `scroll-mt-24`，避免被顶部导航遮挡。
  - `/api/agents` 加载失败时显示明确提示，不再静默显示为暂无代理商数据。
  - 代理商列表按钮补充 `type="button"`。
  - 代理商详情弹窗关闭按钮补充 `aria-label`。
  - 代理商二维码 alt 改为包含代理商公司名。

- `app/page.tsx`
  - 首页页脚原有 `#` 空链接改为真实入口：
    - 官方联系方式：`/contact#contact-info`
    - 全国代理商：`/contact#agents`
    - 邮件：`mailto:support@aimenguning.com`
  - 页脚资源区补充“代理商分布”入口。
