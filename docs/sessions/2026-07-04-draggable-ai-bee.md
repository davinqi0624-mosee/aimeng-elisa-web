# AI 小蜜蜂可拖动优化

日期：2026-07-04

## 背景

前台右下角 AI 小蜜蜂固定在右下角，会遮挡页面底部或右下角内容。用户在需要点击右下角链接、按钮或查看页脚内容时，会被固定客服入口挡住。

## 本次处理

修改文件：

- `components/product/AiChatBot.tsx`

优化内容：

- 小蜜蜂由固定右下角改为可拖动。
- 点击小蜜蜂仍然打开 AI 客服 `/chat`。
- 按住拖动可改变位置，拖动时不会误触跳转。
- 拖动后的位置写入 `localStorage`，刷新页面后会记住上次位置。
- 窗口大小变化时自动把小蜜蜂限制在可视区域内，避免拖到屏幕外。
- 桌面悬浮提示改为“点击打开客服，按住可拖动”。
- 保留键盘可访问性：聚焦后按 Enter/Space 可打开 AI 客服。

## 验证

- `npm run lint -- components/product/AiChatBot.tsx`
- `npm run build`

均通过。
