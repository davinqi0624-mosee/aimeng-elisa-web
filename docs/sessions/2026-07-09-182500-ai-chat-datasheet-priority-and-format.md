# AI 客服：官方说明书优先 + 回复格式优化

时间：2026-07-09 18:25

本轮处理：

- `app/api/ai/chat/route.ts`
  - 接入 `auto_datasheets` 已发布说明书内容，作为 AI 回答的最高优先级上下文
  - 当 ELISA 问题命中对应产品时，优先读取官方说明书章节（样本、操作、洗板、结果等）
  - 明确要求：说明书与知识库冲突时，以说明书为准
  - 明确要求：不要输出 Markdown 表格、`---`、`###`、`|---|` 这类原始格式符号

- `lib/chat-markdown.ts`
  - 新增聊天回复富文本渲染器
  - 支持标题、段落、加粗、列表、表格的友好显示
  - 过滤原始分隔线，避免聊天区出现生硬的 Markdown 符号

- `app/(ai)/chat/page.tsx`
  - AI 回复改为富文本显示，不再直接裸露 Markdown 符号
  - 输入框上方增加轻提示：
    - 鼓励用户对回答点赞/点踩
    - 说明“纠正内容只有审核通过后才会被后续 AI 学习”

结论：

1. ELISA 实验操作类问题，AI 会优先参考你们自己的官方说明书正文；
2. 用户反馈会帮助改进，但不会无审核直接学习；
3. 聊天回复显示会比之前更自然、更温和，表格也会以正常样式呈现。
