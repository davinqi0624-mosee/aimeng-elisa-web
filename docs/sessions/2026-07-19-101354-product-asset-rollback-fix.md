# 产品图片批次撤回修复

## 背景

后台“产品图片”批次中心提示发现错误可以撤回本批次，但实际按钮只有在图片已经“已生效”时才可用。用户上传了文件名不符合规则的标准曲线图片后，图片停留在“待匹配”，无法撤回错误批次。

## 调整

- 前端“撤回本批次”按钮改为：只要当前批次里还有未撤回、未归档图片，就可以操作。
- 撤回确认文案补充实际影响：
  - 未生效图片会从候选记录中撤回，并清理上传文件；
  - 已生效图片会先恢复到本批次生效前的图片位；
  - 如果原来没有图片，会撤下本批次写入的图片。
- 后台接口从只处理 `active` 图片，改为处理当前批次中所有可撤回状态：
  - `pending`
  - `matched`
  - `active`
  - `rejected`
- 对已生效图片执行恢复/撤下逻辑。
- 对本批次上传到 Supabase Storage 的图片文件执行清理。
- 批次状态更新为 `rolled_back`，并记录撤回数量、恢复数量、存储清理数量。

## 验证

均已通过。
