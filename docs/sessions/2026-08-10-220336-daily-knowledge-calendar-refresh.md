# 每日知识日历页视觉升级

## 目标

保留 `/knowledge` 日历核心交互和日期文章映射逻辑，只提升视觉氛围、信息层级和辅助阅读体验。

## 已实现

- 顶部增加“每日知识｜ELISA专业知识日历”导语区域。
- 使用低饱和科技蓝、实验绿和极淡微孔板点阵纹理，避免深色或花哨背景。
- 增加实验排坑、试剂选型、操作技巧三项轻量图标提示。
- 月份切换改为有悬浮反馈的圆角图标按钮，并增加“回到今天”按钮。
- 已发布日期使用浅蓝绿色底色、绿点标记和文章小卡片。
- 当前日期使用浅蓝高亮和蓝色日期圆点。
- 无文章日期显示“待更新”，且不可点击。
- 点击已发布日期先打开文章摘要预览弹窗，用户可再进入阅读全文。
- 底部图例改为圆角标签。
- 日历下方增加：
  - 最近更新 3 篇
  - 按阅读量排序的热门干货 3 篇
  - 真实存在分类的快速筛选

## 数据和交互边界

- 保留原有 `knowledge_base` 与 `daily_knowledge` 两张表按日期合并的逻辑。
- 保留 `/knowledge?month=YYYY-MM` 月份参数。
- 分类筛选使用 `/knowledge?month=YYYY-MM&category=分类`。
- 仅展示数据库中真实存在的分类，避免出现无结果的预设筛选按钮。
- 文章日期仍跳转 `/knowledge/YYYY-MM-DD`，没有更改原详情页路径。
