# 家庭 Wi-Fi 网络排查记录

时间：2026-06-26 22:08 CST

## 背景

用户反馈家中中国移动千兆宽带在无线网络 `CMCC-402-5G` 下速度体验很差，希望判断是网络设置、无线环境还是硬件问题，并给出优化/维护建议。

## 本机诊断结果

- 默认网关：`192.168.10.1`
- 本机 Wi-Fi：`en0`，IPv4 `192.168.10.187`
- Wi-Fi 标准：802.11ax
- 当前 5GHz 信道：36，160MHz
- 信号/噪声：`-58 dBm / -92 dBm`，信号本身可用
- 协商速率：432-576 Mbps，低于千兆宽带下近距离 5GHz/Wi-Fi 6 的理想表现
- 路由器延迟：`ping 192.168.10.1` 30 次无丢包，但延迟抖动很大，平均 24.438ms，最高 125.159ms
- macOS `networkQuality`：下行约 5.846 Mbps，上行约 73.124 Mbps，响应性低；测试端点为 Apple 香港节点，受代理/跨境路径影响可能不代表国内直连宽带
- DNS：系统 DNS 指向 `198.18.0.1`
- 存在 `utun4`，地址 `198.18.0.16 -> 198.18.0.1`
- `223.5.5.5`、`114.114.114.114` 被路由到 `utun4`，ping 100% 超时
- `traceroute www.baidu.com` 显示国内移动链路首跳正常，前 8 跳约 2-14ms

## 初步判断

1. 宽带“千兆”没有充分体现，当前首先应排查 Wi-Fi 链路，而不是直接判断运营商带宽不足。
2. 电脑到路由器的本地延迟抖动异常，说明无线链路/路由器无线设置/干扰有问题。
3. 当前 5GHz 使用 160MHz 频宽，且附近存在多个 5GHz 网络重叠，建议优先改为 80MHz，手动选择较干净的高信道。
4. 本机存在 TUN/DNS 接管，可能影响测速、DNS、国外节点、部分国内 DNS 测试；正式测速前应临时关闭代理/VPN/网络加速器或改为直连。

## 建议优先操作

1. 登录光猫或路由器后台，优先调整 5GHz：
   - 频宽从 160MHz 改为 80MHz
   - 信道手动改为 149、153、157 或 161 中较空的一个
   - 模式保持 Wi-Fi 6/802.11ax
   - 加密使用 WPA2-PSK AES 或 WPA2/WPA3 Personal
2. 将路由器摆放在开阔、高处、远离弱电箱/金属柜/电视背后的位置。
3. 若当前设备是运营商光猫自带 Wi-Fi，建议关闭光猫 Wi-Fi，桥接或 DMZ 给独立 Wi-Fi 6 路由器/AP。
4. 正式测速时先关闭本机代理/VPN/TUN 类工具，再分别测试：
   - 有线直连路由器 LAN 口
   - 距离路由器 1-2 米的 5GHz Wi-Fi
   - 常用房间位置的 5GHz Wi-Fi
5. 若有线能达到 800-950 Mbps，而 Wi-Fi 明显偏低，则重点升级/调整无线设备；若有线也很低，再联系移动检查光猫、入户光功率和账号限速。

## 复测指标

- `ping 192.168.10.1`：理想平均 < 5ms，最高尽量 < 20ms
- Wi-Fi 协商速率：5GHz Wi-Fi 6 近距离应明显高于 576 Mbps
- 国内测速：优先用中国移动官方测速或 Speedtest 选择本地中国移动节点
- 关闭代理后确认 DNS 不再是 `198.18.0.1`

## 路由器管理员账号/密码来源

- 设备型号页面显示为锐捷 `RG-MA3063`。
- 管理员账号和密码优先查看路由器机身底部/背面标签、安装单、移动宽带装机资料，或询问装维师傅/中国移动客服。
- 若浏览器页面上出现钥匙图标或密码管理器提示，可先查看浏览器是否保存过该后台的账号密码。
- 锐捷部分设备默认账号密码可能是 `admin/admin`，但运营商定制或已初始化设备通常会改成标签密码或首次配置密码。
- 忘记密码时可用页面“忘记账号或密码？”流程；最后手段是长按 Reset 恢复出厂，但会清空宽带拨号、Wi-Fi 名称密码、Mesh 等配置，操作前需确认宽带账号/装机信息。
