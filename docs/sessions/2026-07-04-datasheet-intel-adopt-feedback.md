# 说明书生成智能检索采用按钮反馈优化

日期：2026-07-04

## 背景

后台“说明书生成”中，点击“智能检索”后会返回：

- 检测范围 / 灵敏度候选
- 候选简介素材

原问题：点击“采用检测参数”或“采用此简介”后，内容实际已经填入上方输入框，但按钮没有明显颜色变化或状态反馈，管理员需要再回到输入框检查，操作不直观。

## 本次处理

修改文件：

- `app/admin/datasheet/page.tsx`

优化内容：

- “采用检测参数”默认改为蓝色主按钮，不再像普通灰色按钮。
- 点击后按钮变为绿色，并显示“已采用到上方”。
- 被采用的候选参数卡片增加绿色描边和提示文案。
- “采用此简介”点击后变为绿色，并显示“已采用此简介”。
- 候选区顶部增加绿色提示条，明确说明已经填入哪个字段。
- 如果管理员手动修改检测范围、灵敏度或简介，自动清除“已采用”状态，避免误导。

## 验证

- `npm run lint -- app/admin/datasheet/page.tsx`
- `npm run build`

均通过。
