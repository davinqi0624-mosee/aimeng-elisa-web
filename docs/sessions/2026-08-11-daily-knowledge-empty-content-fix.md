# 每日知识空正文修复

## 问题

2026 年 8 月 11 日，“每日知识生成”页面出现“生成成功”，但只显示标题和摘要，正文为空；继续保存时提示缺少 `title`、`content`、`publish_date`。

## 原因

- Kimi K3 生成长篇知识文章时超过旧的 45 秒调用超时。
- 超时后的备用响应可能是空字符串。
- 旧生成接口没有验证正文是否为空，错误地将空响应包装成生成成功。

这不是所选知识主题超出内容范围导致的。

## 修复

- Kimi 长篇生成默认超时调整为 120 秒，并允许通过环境变量覆盖。
- 非流式请求返回空内容时，自动尝试流式读取一次。
- 两种模式均为空时，抛出明确的空响应错误并触发备用模型逻辑。
- 每日知识接口要求标题存在且正文至少 120 个字符；不满足时直接返回生成失败。
- 后台页面在展示和保存前再次校验完整性，不会保存空文章，并显示可读错误提示。

## 验证

- `npx eslint lib/ai/llm.ts app/api/knowledge/generate/route.ts app/admin/knowledge/generate/page.tsx` 通过。
- `npm run build` 通过。
- 已部署后需在后台重新生成当天主题确认。
