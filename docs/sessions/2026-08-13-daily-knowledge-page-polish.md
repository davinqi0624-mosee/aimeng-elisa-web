# 每日知识页布局优化

## 目标

继续优化每日知识日历页，让左右季节视频、中间日历和辅助模块更像一个整体，减少松散感。

## 调整

- 页面最大宽度从 `1680px` 调整为 `1720px`，给左右视频留出更自然的空间。
- 三栏布局从 `180px / 960px / 180px` 提升为 `220px / 980px / 220px` 起步，超宽屏中间可到 `1040px`。
- 中间日历区增加四个状态信息块：
  - 本月发布
  - 节气提示
  - 节日标记
  - 可筛选分类
- 月份标题栏视觉升级为半透明白色主面板，增强层次。
- 日历主体圆角和面板感统一到 `rounded-xl`。
- 手机和平板仍保持单栏，侧边视频不显示，不挤压阅读空间。

## 验证

- `npx eslint app/knowledge/KnowledgeCalendarClient.tsx` 通过。
- `npm run build` 通过。
