# Product Import Invalid Row Details

## 时间
2026-07-13 19:47 CST

## 背景
后台产品批量导入 Excel 后，只显示“需修正”的数量，但没有显示具体哪一行、哪个字段需要修正，维护人员无法回到 Excel 中定位问题。

## 本次处理
- 在后台“商品管理 > 批量导入商品”的预览结果中新增“需修正明细”区域。
- 当存在错误行时，显示：
  - Excel 行号
  - 货号
  - 产品名称
  - 指标
  - 修正原因
- 预览区底部说明调整为：前 8 行只是快速预览，如有错误，以上方“需修正明细”为准。

## 验证
- 本地 `npm run build` 通过。
- 已部署到 `http://106.14.215.238`。
- 部署脚本健康检查通过。
- `http://106.14.215.238/admin/products` 返回 200。

## 使用方式
重新刷新后台页面后，再上传 Excel。如果页面显示“需修正”，下方会出现红色明细表，按表里的行号回到 Excel 修改后重新上传即可。
