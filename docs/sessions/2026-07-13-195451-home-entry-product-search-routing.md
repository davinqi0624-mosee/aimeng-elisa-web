# Homepage Entry Product Search Routing

## 时间
2026-07-13 19:54 CST

## 背景
首页主入口输入货号后点击“智能进入”，原逻辑会固定跳转到 AI 客服页面。客户输入货号时，预期应优先进入产品搜索结果，而不是进入聊天页面。

## 本次处理
- 更新首页主入口提交逻辑：
  - 空输入：进入 ELISA 产品中心。
  - 货号格式，例如 `LV50528`：进入 `/products/elisa?q=LV50528`。
  - COA、批号、质检等关键词：进入 COA 查询页。
  - 明显实验问题，例如“如何操作”“实验方案”“标准曲线不准”：进入 AI 客服。
  - 其他普通关键词：默认进入产品搜索。
- 首页按钮文案从“智能进入”调整为“开始查询”，减少误解。

## 验证
- `npm run build` 通过。
- 已部署到 `http://106.14.215.238`。
- 部署健康检查通过。
- `http://106.14.215.238/products/elisa?q=LV50528` 返回 200。

## 使用方式
刷新首页后，在主输入框输入 `LV50528` 并点击“开始查询”，应进入 ELISA 产品搜索结果页。
