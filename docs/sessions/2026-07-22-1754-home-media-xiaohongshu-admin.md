# 首页自媒体内容与小红书链接后台管理

时间：2026-07-22 17:54

## 需求

用户询问首页自媒体窗口如何链接小红书，以及如何从后台操作。

## 处理

- 新增首页自媒体内容数据模型：
  - 分类：ELISA / 细胞培养
  - 标题
  - 简述
  - 平台
  - 外部链接
  - 封面图
  - 发布时间
  - 排序
  - 左侧置顶
  - 上架显示
- 新增后台页面：`/admin/home-media`
- 新增后台接口：`/api/admin/home-media`
- 新增公共接口：`/api/home-media`
- 首页自媒体窗口改为从 `/api/home-media` 读取内容：
  - 每个分类的置顶内容显示在左侧视频窗口
  - 同分类上架内容显示在右侧“最新动态”
  - 小红书等外链使用新标签打开
- 上传接口增加 `product-assets/home-media/` 目录白名单，用于自媒体封面图上传。
- 存储清理工具增加自媒体封面图引用识别，避免误清理。

## 数据存储

- 新增正式迁移文件：`supabase/migrations/053_home_media_items.sql`
- 当前本地缺少数据库直连 URL，无法直接执行 DDL。
- 为了让后台功能立即可用，新增兼容存储：
  - 如果 `home_media_items` 表已存在，使用独立表。
  - 如果表不存在，自动回退到已有 `site_settings.homepage_content.home_media_items` JSON 存储。

## 验证

- `npx eslint` 通过，仅有后台封面预览 `<img>` 性能提示。
- `npm run build` 通过。
- 已部署到 `http://106.14.215.238`。
- 线上健康检查通过。
- 线上 `/api/home-media` 返回 6 条默认内容，`fallback: true`，说明当前使用备用存储。
- 线上 `/admin/home-media` 返回 200。
- 未登录访问 `/api/admin/home-media` 返回 401，符合后台权限要求。

## 后台操作路径

后台登录后进入：`后台管理 -> 自媒体内容`

操作步骤：

1. 选择内容分类：ELISA 或细胞培养。
2. 填写标题与内容简述。
3. 平台选择“小红书”。
4. 在内容链接中粘贴小红书笔记/视频链接。
5. 上传封面图，或粘贴封面图 URL。
6. 设置排序、是否左侧置顶、是否上架显示。
7. 点击保存。
