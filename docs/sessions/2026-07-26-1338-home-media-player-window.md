# 2026-07-26 首页自媒体视频窗口升级

## 用户需求

用户希望首页上下两个视频窗口不再只是静态文字介绍，而是成为更有叙事感、更能吸引客户的动态媒体窗口：

- 左侧作为主播放/主预览窗口。
- 右侧累计视频可以滚动。
- 点击右侧视频后，左侧切换到对应内容。
- 如果视频可以直连播放，就静音循环播放。
- 如果视频来自剪映/小红书等网页链接，则保留外链观看完整视频，但首页仍要有动态、有生命力。

## 实现内容

- 修改 `app/page.tsx`。
- 首页自媒体区域改为 `Media Studio`。
- ELISA 与细胞培养分成两个独立媒体区。
- 左侧改为主媒体窗口：
  - 支持 MP4/WebM/Ogg 直链时 `<video>` 静音循环播放。
  - 非直链网页视频使用封面、科技感覆盖层、播放状态和叙事文案做动态预览。
  - 支持点击“看完整版”进入外部自媒体平台。
- 右侧改为播放队列：
  - 显示封面缩略图、分类、标题、平台。
  - 可滚动。
  - 点击队列项目后，左侧主窗口立即切换。
- 排序优化：
  - 真实后台上传的视频链接优先于默认占位内容。
  - 用户上传的“一个视频让你速通ELISA实验”会优先进入 ELISA 主窗口。

## 技术说明

- 剪映链接 `https://www.capcut.cn/share/...` 是网页链接，不是视频文件直链，不能直接作为 `<video src>` 播放。
- 当前逻辑真实区分：
  - 直链视频：站内直接播放。
  - 平台网页链接：站内动态预览，点击跳转平台观看完整内容。
