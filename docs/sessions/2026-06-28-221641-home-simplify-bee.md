# 2026-06-28 首页内容精简和小蜜蜂调整

## 用户反馈

- 首页结构大方向可以，但内容偏重、重复、拖拉。
- 希望首页作为网站窗口，更简单明了、大气简约。
- 首页企业 IP 小蜜蜂可以小范围飞动，但手机版操作时会挡住输入框，影响输入文本和发送。

## 已处理

- `app/page.tsx`
  - 首页主体改为：
    - 顶部轮播。
    - 核心服务入口：产品中心、ELISA 数据分析、AI 实验助手、文献积分。
    - 产品中心简洁引导：ELISA 试剂盒、胎牛血清、动物血制品、COA 查询。
    - 资料/选型/实验支持入口条。
  - 不再在首页完整展开流程、视频、方法学、每日知识、社区、积分商城等长区块。
  - 旧区块函数暂时保留，下一轮 `F1-home-lint` 再统一删除或归档，避免本轮变成大范围重构。

- `components/AppChrome.tsx`
  - `/chat` 和 `/ai-chat` 页面隐藏悬浮小蜜蜂，避免挡住聊天输入框和发送按钮。

- `components/product/AiChatBot.tsx`
  - 移动端尺寸从大图标改为 `h-16 w-16`。
  - 移动端位置改为 `bottom-20 right-3`。
  - tooltip 在移动端隐藏，只在 `sm` 以上显示。

- `components/product/AiChatBot.css`
  - 小蜜蜂飞行动效幅度收小。
  - 动画速度放慢，改成更轻微的浮动。
