## 已处理问题

1. 样本结果展示不够清楚
   - 原来未知样本只有一个“浓度”字段，低于量程、高于量程、无法反算、0 值容易混淆。
   - 已拆分为“反算浓度 / 最终浓度 / 判定”。
   - 判定包含：正常、低于量程、高于量程、无法反算。

2. 报告缺少孔位回查能力
   - 报告页增加 96 孔位结果矩阵。
   - TXT 导出增加 96 孔位结果矩阵。
   - 原始孔板导入时，标准品第一列会带 A01-H01 孔位，样本列继续保留 A02-H12 孔位。

3. 旧报告接口存在未来陷阱
   - `/api/reports` 原来只兼容旧版 `/api/analyze` 返回结构，若接入当前 `/lab/analysis` 的 `fitResult` 会出错。
   - 已改为同时兼容旧结构和当前结构，并补充 HTML 转义，避免原始数据内容影响报告页面。

4. 截图识别和报告接口错误提示不够稳
   - OCR 错误处理移除 `any`，兼容中转平台返回的非标准错误结构。
   - `/api/analyze`、`/api/reports` 的 catch 类型已收窄。

5. E1 范围 lint 债务
   - 清理 `app/lab/analysis/page.tsx` 未使用图标、旧备用函数、旧状态。
   - E1 scoped lint 已清零。

## 追加进展：空白扣除规则

时间：2026-06-28

已完成第一版空白扣除：

- 拟合设置新增“空白处理”。
- 默认选项为 `保留空白`，不改变历史计算结果。
- 可切换为 `扣除 Blank`，所有标准品和样本 OD 会扣除 0 浓度标准品平均 OD。
- 如果选择扣除 Blank 但数据中没有 0 浓度标准品，系统会阻止拟合并提示原因。
- 报告页、TXT 报告、Excel 报告都会写明空白处理规则和 Blank 平均 OD。
- Excel `原始数据` 工作表保留原始 OD；`整理后数据` 同时展示原始 OD 和校正 OD。
