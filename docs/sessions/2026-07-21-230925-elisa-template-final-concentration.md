# 2026-07-21 ELISA 模板终浓度列修复

## 背景

用户反馈从网站下载的 ELISA 数据分析 Excel 模板最后一列仍停留在“样品稀释倍数”，没有新增“终浓度(pg/mL)”列。网站 4PL 计算中样本已有终浓度，但标准品终浓度展示和模板结构未完全对齐。

## 本次变更

- 升级 `public/downloads/AM-ELISA数据分析模板.xlsx`：
  - 表格范围从 `A1:E97` 扩展为 `A1:F97`。
  - 第 6 列新增表头：`终浓度(pg/mL)`。
- 调整 ELISA 数据导入解析规则：
  - 新增 `终浓度/最终浓度/反算浓度` 不再被误识别为标准品“已知浓度”。
  - 标准品已知浓度继续优先识别明确的浓度列；模板没有已知浓度列时，仍按 A-H 行 + 01 列自动映射默认标准品浓度。
- 模板下载接口增加版本参数，避免浏览器缓存继续下载旧模板。

## 验证

- 读取模板确认表头为：`位置 / 名称 / 类型（标准品/空白孔/检测样品） / OD值（波长:450nm） / 样品稀释倍数 / 终浓度(pg/mL)`。
- `npx eslint app/lab/analysis/page.tsx app/api/lab/analysis/template/route.ts` 通过。
- `npm run build` 通过。
