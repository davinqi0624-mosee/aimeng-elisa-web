# 2026-08-22 ELISA 4PL 标准曲线修复

## 背景

用户反馈客户上传 AM-ELISA 数据分析模板后，网站生成的标准曲线异常：标准品点全部贴近 X 轴，Y 轴看起来没有有效数据；拟合参数中 C/EC50 和 D/Top 出现天文数字，导致图表坐标轴被极端值撑坏。

## 处理

- 在 `app/lab/analysis/page.tsx` 中为 4PL 拟合增加参数边界，限制 A/Bottom、B/Hill、C/EC50、D/Top 在 ELISA OD 数据的合理范围内，防止无边界优化跑飞。
- 图表 Y 轴不再直接使用 `params.D` 作为最大值来源，改为依据实际标准品/样本 OD 与有效曲线采样点计算，避免异常参数把曲线压平。
- X 轴以标准品浓度范围为主体，超出量程的未知样本通过表格状态提示，不再拉伸标准曲线图。
- 增加标准品 OD-浓度趋势检查。如果浓度由低到高时 OD 明显不递增，会在质控提示中提醒检查模板浓度、孔位和 OD 对应关系。

## 验证

- `npm run lint -- app/lab/analysis/page.tsx` 通过。
- `npm run build` 通过。
- `npm run deploy:aliyun` 已部署到 `https://animaluni.com`。
- 部署健康检查通过，包括 `/lab/analysis`。
- 使用典型标准品数据 `[0,125,250,500,1000,2000,4000,8000]` 与 OD `[0.034,0.140,0.428,0.529,0.740,1.090,1.995,2.420]` 做计算层验证，4PL 参数均为有限值，预测 OD 正常递增。

## ELISACalc 对齐补充

用户进一步反馈同一组数据与 ELISACalc 的反算浓度仍有差异。复核发现：此前为避免图表被异常 Top 参数压扁，将 4PL 的 D/Top 上限限制得过紧。该限制让标准品范围内 R² 仍然很高，但会影响样本 OD 的反算浓度。

截图数据复算：标准品浓度 `[0,62.5,125,250,500,1000,2000,4000]`，OD `[0.0539,0.1774,0.2668,0.3543,0.5593,0.9179,1.4533,2.3344]`。

- 调整后网站参数：`A≈0.06015, B≈0.73484, C≈234712.58, D≈47.67626, R²≈0.999765`。
- ELISACalc 参数等价为：底部 `D≈0.06015`、顶部 `A≈47.67705`、`B≈-0.73484`、`C≈234718.63`。
- 样本 OD `0.2414` 反算约 `120.308 pg/mL`，与 ELISACalc `120.30774` 对齐。

处理方式：放宽 D/Top 的拟合上限，保留图表 Y 轴保护逻辑。因此计算结果可接近 ELISACalc，同时不会再次出现标准曲线被天文参数压平的问题。
