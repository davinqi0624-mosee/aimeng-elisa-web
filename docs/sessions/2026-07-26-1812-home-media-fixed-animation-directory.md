# 2026-07-26 首页自媒体区固定动画窗口与视频目录调整

## 用户反馈

- 上方 ELISA 视频窗口和下方细胞培养视频窗口尺寸不一致，细胞培养窗口偏小，不协调。
- 右侧滚动视频列表内容显得杂乱。
- 希望每个频道使用一个长期播放的动画视频窗口；客户点击对应视频时再跳转到对应视频或链接。

## 调整内容

- 修改 `app/page.tsx`。
- ELISA 与细胞培养两个频道统一布局：
  - 左侧固定为同尺寸主动画窗口。
  - 右侧固定为视频目录。
  - 不再把第二个频道反向排版，避免窗口宽度不一致。
- 主动画窗口不再随右侧列表切换：
  - 每个频道保留一个长期展示的动态预览。
  - 动画包括封面慢推、扫描线、光圈脉冲、数据条跳动、实验脚本轮播。
- 右侧列表改为干净的视频目录：
  - 点击条目直接进入对应外部视频/链接。
  - 如果频道已有真实外链，只展示真实外链视频，默认占位内容不再混入。
  - 如果频道还没有真实视频，才显示默认占位内容。

## 验证

- `npx eslint app/page.tsx --quiet`
- `npm run build`
- `npm run deploy:aliyun`
- 线上健康检查通过。
