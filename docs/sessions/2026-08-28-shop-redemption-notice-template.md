# 积分商城固定兑换须知

日期：2026-08-28

## 需求

商品描述中不再重复粘贴售后提示。兑换提示统一放在固定位置，管理员以后只填写商品自身介绍。

统一文案：

> 积分兑换时请留好快递信息，如有变动方便客服人员联系，正常发货时间为兑换后7个工作日，以沟通结果为准，积分兑换商品，兑换后不可退换货，敬请谅解！

## 实施内容

- 新增 `lib/shop/constants.ts`，集中维护固定文案和旧文案清理逻辑。
- 商品详情预览和兑换申请弹窗均增加固定的“兑换须知”区域。
- 后台新增和编辑商品时，服务端自动剥离固定兑换提示，即使管理员误粘贴也不会保存到商品描述。
- 后台描述输入框下方增加提示，说明固定文案由系统统一展示。
- 清理数据库中已有商品描述里的两种旧版本固定文案。

## 数据清理结果

- 商品总数：69 个。
- 含旧固定提示并清理：63 个。
- 不含固定提示、未修改：6 个。
- 清理后仍含旧提示：0 个。
- 商品自身描述内容保留，未删除图片、积分、库存或其他字段。

## 后续使用

后台新增或编辑商品时，只在“描述”中填写商品介绍。固定兑换须知会自动出现在商品详情和兑换申请中，不需要再次粘贴。
