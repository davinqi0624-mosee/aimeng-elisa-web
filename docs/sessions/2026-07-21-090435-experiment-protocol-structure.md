# 2026-07-21 实验方案生成器按实验类型重构

## 背景

用户指出实验方案生成器把 ELISA 的字段结构套用到所有实验类型上：

- “样本类型”加必填星号主要适用于 ELISA 试剂盒选型，不适合强制用于 WB、IHC、细胞实验和生化检测。
- 细胞实验更关心细胞名称、来源、类型、培养条件、处理分组和检测终点。
- 更合理的方式是先按不同实验的 protocol 结构寻找线索，而不是让客户填写过细、过固定的表单。

## 本次改动

- 重构 `app/lab/experiment/page.tsx`：
  - 必填项只保留“实验类型”和“实验目的 / 研究问题”。
  - 选择 ELISA 时显示“ELISA 推荐补充信息”：样本种属、样本类型、检测指标、样本数量/分组。
  - 选择细胞实验、WB、IHC、生化检测时，不再展示 ELISA 字段。
  - 增加“已知实验信息”自然语言输入框，placeholder 会随实验类型变化。
  - 右侧动态展示当前实验类型的 protocol 结构和设计线索。
- 更新 `app/api/experiment/generate/route.ts`：
  - 不再要求 `sampleType` 必填。
  - 根据实验类型注入对应 SOP/protocol 结构。
  - 信息不完整时，要求 AI 先输出可执行框架，再列出需要补充确认的问题。

## 五类实验结构

- ELISA：检测指标、样本与分组、试剂盒/标准曲线、加样孵育洗板显色、4PL 和质控判断。
- 细胞实验：细胞来源、培养条件、铺板密度、处理分组、检测终点、状态和污染控制。
- WB：蛋白提取、定量上样、电泳转膜、封闭抗体孵育、显色、灰度归一化。
- IHC：组织固定切片、脱蜡/预处理、抗原修复、封闭抗体孵育、显色复染、评分判读。
- 生化检测：指标和方法确认、样本前处理、试剂/标准品、反应体系和波长、单位换算和质控。
