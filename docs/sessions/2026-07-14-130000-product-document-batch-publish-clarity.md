# 2026-07-14 13:00 产品文档批次上架状态说明优化

## 背景

后台产品文档管理中，最新说明书批次显示：

- 上传到后台：90/90
- 货号匹配成功：90/90
- 上架到网站前台：0/90

用户点击“批次刷新”后数字没有变化，容易误解为刷新失败。

## 核查结果

线上数据库确认该批次状态为：

- 批次：说明书批量上传 101 个文件
- 实际成功入库文件：90 个
- 90 个全部已按货号精确匹配
- 90 个仍为 pending，尚未确认上架
- 因此前台可见数量为 0/90 是正确状态，不是刷新失败

## 本次调整

- 将“批次刷新”改为“刷新状态”，明确它只重新读取状态，不会自动上架。
- 将确认按钮改为“一键上架 N 个”，直接显示待上架数量。
- 当有已匹配但未上架文件时，在批次中心显示提示：需要点击“一键上架”后前台产品页才会显示说明书。
- 批量上架接口只处理 pending 的精确匹配文件，避免已撤回批次被误上架。
- 确认上架后，文档匹配备注从“待管理员确认后生效”更新为“已确认上架，前台可见”。
- 已撤回批次显示“恢复本批次”入口，恢复后再进行确认上架。

## 验证

- `npm run build` 通过。
- `npm run deploy:aliyun` 已部署到 `http://106.14.215.238`。
- 部署后健康检查通过。

## 操作说明

当前 90 个文件仍未自动上架。管理员需要在后台产品文档管理中点击“一键上架 90 个”，完成后前台产品页才会显示这些说明书。
