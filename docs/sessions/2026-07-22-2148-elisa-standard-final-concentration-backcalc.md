# 2026-07-22 ELISA 报告标准品终浓度修正

## 用户反馈

4PL 拟合计算生成的报告中，标准品的「终浓度(pg/mL)」显示成了已知浓度。用户确认这是不对的，标准品终浓度也应该来自反算浓度。

## 修正内容

- 修改 `app/lab/analysis/page.tsx` 中标准品终浓度计算逻辑。
- 标准品「终浓度」统一使用 `反算浓度`，不再使用已知浓度。
- 标准品默认稀释倍数为 1，因此终浓度与反算浓度一致。
- 覆盖位置：
  - 页面标准品拟合表
  - 96 孔位矩阵
  - TXT 报告导出
  - Excel 报告「整理后数据」
  - Excel 报告「标准品拟合详情」

## 验证

- `npx eslint app/lab/analysis/page.tsx`
- `npm run build`
- `npm run deploy:aliyun`
- 线上健康检查通过

## 备注

旧的已下载报告不会自动变化，需要刷新页面后重新上传/重新计算并导出报告。
