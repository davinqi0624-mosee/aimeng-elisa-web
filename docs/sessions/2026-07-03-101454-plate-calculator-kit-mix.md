# 2026-07-03 酶标板孔数计算器规格组合修正

## 背景

用户反馈酶标板孔数计算器只按总孔数粗略推荐 96T，导致：

- 91 个单孔样本 + 单孔标准曲线时，页面推荐 `2 块 96T`，但更合理方案应为 `1 块 96T + 1 块 48T`。
- 180 个单孔样本 + 单孔标准曲线时，页面推荐 `2 块 96T`，但 2 块 96T 的真实样本承载量只有 `88 × 2 = 176`，无法完成 180 个样本，应推荐 `2 块 96T + 1 块 48T`。

## 核心规则

- 每块板都建议重新做标准曲线。
- 标准曲线为 8 点：S1-S7 + Blank。
- 单孔标准曲线时：
  - 96T 实际可测样本孔：`96 - 8 = 88`
  - 48T 实际可测样本孔：`48 - 8 = 40`
- 双孔标准曲线时：
  - 96T 实际可测样本孔：`96 - 16 = 80`
  - 48T 实际可测样本孔：`48 - 16 = 32`
- 推荐排序：
  - 先保证样本孔数足够。
  - 优先板数最少。
  - 板数相同时优先余量最小，减少客户浪费。
  - 不再简单用总孔数除以 96T。

## 已修改

- `components/calculator/PlateCalculator.tsx`
  - 新增 96T/48T 组合推荐算法。
  - 推荐结果支持 `1 块 96T + 1 块 48T`、`2 块 96T + 1 块 48T` 等混合规格。
  - 推荐卡片显示总容量、实际占用、余量、可测样本孔。
  - 将“总需求孔数”改为“单板基础需求孔数”，避免多板实验时误解。
- `app/api/ai/chat/route.ts`
  - 同步 AI 客服中的酶标板孔数计算规则。
  - 增加 91 样本和 180 样本示例。
- `app/api/experiment/generate/route.ts`
  - 同步实验方案生成接口中的孔数计算规则。
  - 顺手清理该文件中本轮触发的历史 `any` 异常处理。

## 算法验证

- `91` 个单孔样本，单孔标准曲线：
  - 推荐：`1 块 96T + 1 块 48T`
  - 可测样本孔：`88 + 40 = 128`
  - 实际占用：`91 + 8 × 2 = 107`
  - 余量：`37`
- `180` 个单孔样本，单孔标准曲线：
  - 推荐：`2 块 96T + 1 块 48T`
  - 可测样本孔：`88 × 2 + 40 = 216`
  - 实际占用：`180 + 8 × 3 = 204`
  - 余量：`36`
