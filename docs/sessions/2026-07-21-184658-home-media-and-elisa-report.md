# 2026-07-21 首页自媒体区与 ELISA 报告修复

## 背景

用户希望首页更简约大气，去掉实用价值不高或重复的首页区域，并将自媒体内容按应用场景分成两个明确模块：

- ELISA 实操视频区域
- 细胞培养 / 血清相关视频区域

同时，ELISA 数据分析在计算结果已正确的情况下，报告中标准品的终浓度仍未完整显示，需要补齐。

## 本次变更

- 首页移除未再展示的旧模块代码：客户常用 4 件事、Product Center 三条产品线说明。
- 首页自媒体内容改为两个独立展示区，每个展示区包含：
  - 左侧视频窗口入口
  - 右侧最新动态列表
- ELISA 数据分析报告补齐标准品终浓度字段：
  - 页面报告表
  - TXT 报告
  - Excel 报告 Sheet
  - 整理后数据 Sheet
  - 数据表格页标准品拟合详情

## 验证

- `npx eslint app/page.tsx app/lab/analysis/page.tsx` 通过。
- `npm run build` 通过。

## 后续建议

- 自媒体视频窗口后续可接入后台可配置链接，用于手动维护小红书、视频号、抖音或 B 站视频地址。
- 若平台提供稳定 API 或 RSS，再考虑自动同步最新视频。
