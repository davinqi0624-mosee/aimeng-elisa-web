# Assay Time Label And Bulk Fix

## 时间
2026-07-14 08:31 CST

## 问题
产品详情页中 `assay_time` 字段显示为“检测时间”，用户希望改为“操作时长”。同时猴子和猪产品已上传，`assay_time` 写入了错误时长，需要统一修正为 `4h`。

## 本次处理
- 前台产品详情页：
  - “检测时间”改为“操作时长”。
  - 默认值从 `4h 30m` 改为 `4h`。
- 后台商品管理：
  - 编辑表单字段名改为“操作时长”。
  - 占位值改为 `4h`。
  - 批量导入字段别名保留兼容：`操作时长`、`检测时间`、`assay_time` 都可识别。
- Excel 批量导入模板：
  - 表头从 `检测时间(assay_time)` 改为 `操作时长(assay_time)`。
  - 示例值改为 `4h`。
- 数据库批量修正：
  - `Monkey` active 产品：528 条，全部改为 `4h`。
  - `Porcine` active 产品：591 条，全部改为 `4h`。
  - 旧值 `3h 30m` 剩余 0 条。

## 关于撤回
后台已有“批量导入记录”入口，支持对商品批量导入批次做回滚。但本次问题只涉及单字段修正，直接批量更新 `assay_time` 比整批撤回重传更合适。
