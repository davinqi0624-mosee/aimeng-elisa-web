# 酶标板孔数计算器 Blank 规则修正

## 背景

用户指出 `/lab/calculator` 中“空白对照孔”不应该作为单独选项。AIMENG UNING 说明书中的 8 点标准曲线已经是 `S1-S7 + Blank`，如果再让客户选择 1 孔或 2 孔空白对照，会造成 Blank 被重复计入。

## 修改内容

- 修改 `components/calculator/PlateCalculator.tsx`
  - 移除“空白对照孔”选择按钮。
  - Blank 孔随标准曲线自动计算。
  - 总孔数公式改为：`标准曲线孔数（8 点 × 标准品平行，已包含 Blank）+ 样本数 × 样本平行次数`。
  - 对 20 个样本、标准曲线双孔、样本双孔的情况，总孔数从错误的 `58 孔` 修正为 `56 孔`。

- 修改 `app/api/experiment/generate/route.ts`
  - 实验方案生成提示同步改为 Blank 已包含在标准曲线中，不额外加空白孔。

- 修改 `app/api/ai/chat/route.ts`
  - AI 客服孔数计算规则同步修正。
  - 删除“确认空白对照孔数”的问诊步骤。
  - 示例改为 `10 样本双孔 + 双孔标准曲线 = 16 + 20 = 36 孔`。

## 验证

- `npm run build` 通过。
- 全局搜索已清理旧口径：不再出现“标准品孔数 + 空白对照孔”的额外加孔公式。
