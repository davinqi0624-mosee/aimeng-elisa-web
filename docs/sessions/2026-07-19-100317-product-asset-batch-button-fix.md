# 产品图片批次按钮状态修复

## 背景

后台产品图片上传后，标准曲线图页面显示待匹配图片，但“自动匹配”和“确认精准匹配”按钮不可点击。截图中批次筛选停留在“全部批次 / 不按批次筛选”，导致批次操作没有具体 batch_id。

## 调整

- 上传完成后自动选中本次新建批次，并立即加载该批次的图片记录。
- 批次列表加载后，如果当前没有选择批次，会默认选择最新批次。
- 将批次下拉的空选项改为“请选择具体批次”，避免误解为可以对全部批次统一操作。
- 在批次中心增加操作提示：
  - 未选择批次时提示必须选择具体批次；
  - 待匹配时提示先点击“自动匹配”；
  - 已匹配时提示可以确认生效；
  - 已生效时说明前台产品页会读取这些图片。
- 给禁用按钮增加 hover title，说明禁用原因。

## 验证

- `npx eslint app/admin/product-assets/page.tsx`
- `npm run build`

均已通过。

## 说明

如果上传的标准曲线图片文件名是微信图片这类随机名称，系统无法自动识别货号、种属和指标名称。建议命名为：

```text
LV30325__Mouse__IL-6__standard_curve.png
Mouse__IL-6__standard_curve.png
```

系统优先按货号匹配，其次按“种属 + 指标名称”唯一匹配。
