# 积分商城积分排序

日期：2026-09-01

## 修改内容

- 在积分商城商品分类筛选旁增加“积分排序”下拉菜单。
- 支持默认顺序、积分从低到高、积分从高到低。
- 积分排序与商品类别筛选可以同时使用。
- 登录用户按照会员折扣后的实际兑换积分排序；未登录时按照商品原始积分排序。
- 相同积分商品按名称排序，避免列表顺序不稳定。

## 影响范围

- 仅修改 `app/(shop)/store/page.tsx` 前台展示逻辑。
- 不修改商品数据、库存、兑换扣分和会员折扣规则。
- 不需要新增数据库迁移。
