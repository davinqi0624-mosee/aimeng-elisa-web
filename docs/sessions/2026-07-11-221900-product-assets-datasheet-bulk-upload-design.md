# 产品图片与说明书批量上传方案设计

时间：2026-07-11 22:19 CST

## 目标

产品资料分三类处理：

1. 产品文字信息：继续使用 Excel 批量导入。
2. 产品图片：不要放 Excel；通过后台批量上传文件并自动匹配产品。
3. 产品说明书 PDF：不要放 Excel；通过后台批量上传 PDF 并自动匹配产品。

核心目标是降低错误率，避免几千份说明书或图片上传错位后难以排查。

## 产品图片策略

图片位规划：

1. 第 1 图片位：产品广告图，所有 ELISA 产品固定使用同一张默认图。
2. 第 2 图片位：标准曲线图，按“种属 + 指标/靶标”或货号自动匹配。
3. 第 3 图片位：方法学图片，所有双抗夹心法产品固定使用同一张默认图。
4. 第 4 图片位：备用图片，可留空或后续批量上传。
5. 第 5 图片位：预留扩展图片位，暂不强制使用，未来可放应用案例图、包装图、实验流程图或质控图。

推荐实现：

- 固定图不进入 Excel，不需要每个产品重复上传。
- 固定图放在网站公共资源目录或后台统一配置中。
- 标准曲线图走“标准曲线图片批量上传”模块。

## 文件命名规则

### 标准曲线图片

推荐命名：

```text
种属__指标名称__standard_curve.png
Mouse__IL-6__standard_curve.png
Human__TNF-alpha__standard_curve.jpg
```

如果已经有货号，也可以更稳：

```text
货号__种属__指标名称__standard_curve.png
LV10001__Mouse__IL-6__standard_curve.png
```

匹配优先级：

1. 货号精确匹配。
2. 种属 + 指标名称精确匹配。
3. 低置信度模糊匹配只进入人工确认，不自动生效。

### 产品说明书 PDF

推荐命名：

```text
货号__种属__指标名称.pdf
LV10001__Mouse__IL-6.pdf
```

匹配优先级：

1. 货号精确匹配，最高优先级。
2. 种属 + 指标名称精确匹配。
3. 文件名缺货号但能唯一匹配“种属 + 指标”时，可进入待确认。
4. 多个产品匹配或无匹配时，不自动绑定。

## 批量上传流程

### 第 1 步：上传文件

后台新增两个入口：

- 标准曲线图片批量上传
- 说明书 PDF 批量上传

每次上传生成一个批次号 `batch_id`。

### 第 2 步：预检，不立即生效

系统读取文件名，生成预检结果：

- 绿色：高置信度精确匹配。
- 黄色：可能匹配，但需要人工确认。
- 红色：无法匹配、重复文件、命名不合规或文件格式错误。

预检阶段不影响前台产品页面。

### 第 3 步：管理员确认

管理员看到：

- 文件名
- 解析出的货号、种属、指标
- 匹配到的产品
- 匹配原因
- 文件大小
- 文件哈希
- 是否与已有文件重复

只允许：

- 批量确认绿色项
- 黄色项逐条确认或改绑
- 红色项下载错误清单后重新整理

### 第 4 步：确认后生效

确认后：

- 标准曲线图写入对应产品的第 2 图片位。
- 说明书 PDF 写入 `product_documents`，前台详情页显示“下载说明书”。
- 如果同一产品已有旧说明书或旧标准曲线图，旧文件自动归档，不直接删除。

### 第 5 步：可回滚

每个批次保留：

- 上传文件列表
- 绑定结果
- 旧文件归档记录
- 操作管理员
- 操作时间

如果发现整批错误，可以一键回滚该批次：

- 新绑定撤销
- 老文件恢复 active
- 新文件转 archived

## 批量操作撤回与格式化

所有批量操作都必须有“可撤回”的批次记录，不允许直接覆盖且无法追溯。

### 产品文字信息 Excel 批量导入

要求：

- 每次导入生成 `batch_id`。
- 记录本批次创建了哪些产品、更新了哪些产品、导入前原始值是什么。
- 支持“撤回本批次”：
  - 本批次新建的产品：可批量归档或删除。
  - 本批次更新的产品：恢复导入前字段。
- 不建议默认做“全站产品格式化”，风险较高。
- 如果必须格式化，应仅限超级管理员，并且必须先导出完整备份。

### 产品图片批量上传

要求：

- 每批图片上传生成 `batch_id`。
- 确认生效前只进入待审核，不影响前台。
- 确认生效后记录旧图片位内容。
- 支持“撤回本批次”：
  - 新图片撤下或归档。
  - 原图片位恢复到上传前状态。
  - 固定图不受撤回影响，除非管理员明确修改固定图配置。

### 产品说明书 PDF 批量上传

要求：

- 每批 PDF 上传生成 `batch_id`。
- 确认生效前只进入待确认，不影响前台。
- 同一产品旧说明书自动归档，不直接删除。
- 支持“撤回本批次”：
  - 本批新说明书转 archived。
  - 本批覆盖前的旧说明书恢复 active。
  - 批次记录保留，方便追溯。

### 一键格式化

“一键格式化”只作为兜底功能，不作为常规操作。

建议分三类：

1. 格式化产品文字导入批次：撤回本批新增/更新。
2. 格式化图片批次：撤回本批图片绑定。
3. 格式化说明书批次：撤回本批 PDF 绑定。

不建议做一个“全站清空重来”按钮。若未来确实需要，应满足：

- 超级管理员权限。
- 操作前强制备份数据库和文件绑定表。
- 二次确认，输入确认文字。
- 只清理本次批量导入产生的数据，不删除人工维护的数据。

## 错误预防规则

1. 不允许批量确认低置信度匹配。
2. 同一个文件哈希重复上传时提醒。
3. 同一产品同一类型文件只允许一个 active，其余自动 archived。
4. 文件名解析不到货号，也解析不到“种属 + 指标”，不允许自动绑定。
5. 同一“种属 + 指标”匹配多个产品时，不允许自动绑定。
6. 每次批量操作必须有错误报告和批次记录。

## 存储建议

说明书约 8MB/份，几千份会达到数十 GB。建议：

- 使用 Supabase Storage 或对象存储作为正式文件库。
- 不建议使用百度网盘、夸克网盘、微信文件等普通分享链接。
- 网站只保存文件 URL、文件路径、哈希和绑定关系。
- 原文件不放 Excel。

## 最终后台结构建议

后台分为三个入口：

1. 产品文字信息批量导入：Excel。
2. 产品图片批量上传：产品固定图配置 + 标准曲线批量匹配。
3. 产品说明书批量上传：PDF 批量匹配、确认、归档、回滚。

## 实施顺序

1. 固定 ELISA 第 1 图片位和第 3 图片位。
2. 预留第 4、第 5 图片位的数据结构和前台展示位置。
3. 扩展标准曲线图片批量上传和匹配。
4. 加强说明书 PDF 批量上传的命名解析、预检和回滚。
5. 给产品文字 Excel 导入增加按批次撤回。
6. 增加批次错误报告下载。
7. 再考虑批量清理归档文件。

## 2026-07-11 第一阶段落地

- 产品详情页图片窗口已支持 5 位展示布局。
- 第 1 位在没有产品专属图时自动使用固定产品展示图。
- 第 3 位在没有产品专属方法/验证图时自动使用固定方法学图。
- `product_images.image_type = reserved` 可作为第 5 预留图片位进入前台展示。
- 过滤了早期迁移中自动塞入的默认 `product_images`，避免旧默认图污染新图片位规划。
- 本阶段不需要新增 SQL；后续标准曲线图和说明书批量上传再补批次预检/撤回逻辑。
