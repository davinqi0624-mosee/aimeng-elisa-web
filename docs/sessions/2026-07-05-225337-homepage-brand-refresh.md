# 首页品牌感与功能入口精简

日期：2026-07-05

## 背景

用户反馈首页“没有新意”，但网站整体架构已经稳定，不适合做大结构推翻。目标是做首页内容减法，明确主角，增强第一眼的品牌感，同时为后续小红书等自媒体内容窗口预留位置。

## 本轮调整

- 将首页首屏从轮播主导改为固定的“智能实验服务入口”。
  - 主标题聚焦“爱萌优宁 ELISA 与细胞培养产品服务平台”。
  - 增加靶标、货号、COA 批号、实验问题输入框。
  - 保留产品检索、COA 查询、ELISA 数据分析、联系客服四个高频入口。
- 将原首页轮播降级为“精选动态与活动窗口”。
  - 继续使用现有 `/api/home-banners` 和后台广告位能力。
  - 不再让活动/动态轮播承担首页第一印象。
- 新增自媒体内容展示区。
  - ELISA 实验内容和血清/细胞培养内容分开展示。
  - 为未来接入小红书等平台预留内容橱窗。
- 精简产品线表达。
  - ELISA 试剂盒、胎牛血清、动物血制品分开说明。
  - 首页只做清晰引导，详细参数进入内页。
- 调整页脚文案。
  - 从偏 AI 平台表达改为产品资料、批次追溯和智能实验支持的品牌口径。

## 修改文件

- `app/page.tsx`
- `components/home/HomeHeroCarousel.tsx`

## 验证

- `npm run lint -- app/page.tsx components/home/HomeHeroCarousel.tsx`
- `npm run build`

两项均通过。

## 后续建议

- 后台首页广告位可继续用于活动、品牌动态、重点内容，但建议不再堆 9 条默认轮播。
- 后续可以把 `/videos` 页面升级为真正的“自媒体内容中心”，按 ELISA、胎牛血清、动物血制品分栏目管理。
- 如需进一步增强首屏质感，可替换为更真实的产品/实验室照片，而不是继续依赖示意图。
